# Clinical Guidelines dashboard SOP

[Download the illustrated SOP](mediguide-clinical-guidelines-dashboard-sop.pdf)

Version 2.0, prepared 25 October 2026. The 91-page PDF contains 28 procedures,
56 dashboard/public-reader screen plates (including enlarged details), and two
existing Android app screenshot plates. It covers source upload, Markdown
editing, images, tables, revision history, regeneration, review, acceptance,
publication, website verification, mobile/offline verification and aftercare.

## Capture scope

The first library screen is a read-only production capture. Authoring examples
use a local, non-clinical `TRAINING ONLY` document, version `SOP-2026.1`.
That training draft reached accepted regeneration and 9/9 reviewed blocks.
The final publication confirmation was inspected and canceled. Published-state
and public-reader examples use a separate, existing local fixture.

Dashboard mobile-width previews are labeled as previews. Android reference
screens come from the repository's existing store screenshot assets and show
a different guideline. The PDF does not claim that the training draft was
published or passed on-device offline testing. No production clinical records
were changed to prepare this guide.
